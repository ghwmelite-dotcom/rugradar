# Daily posting kit — RugRadar

Everything you need to post daily in ~5 minutes.

## Assets (outputs/x/assets/)

| File | Use for |
|---|---|
| `screenshot-home.png` | Pinned tweet / launch thread post 1-2 (the scanner + trending) |
| `screenshot-report.png` | Launch thread post 3 / any "how it works" post (score dial + red flags + deployer card) |
| `screenshot-feed.png` | Launch thread post 5 / Wall of Shame posts |
| `rug-report-2026-08-21.png` | Today's Rug Report card (2400×1350, X-optimized) |
| `icon.svg` | Logo source |

## Daily routine (5 min)

1. Open https://rugradar.trademetricspro.com/feed — note: tokens scanned,
   honeypots caught, and the riskiest token (most red flags / lowest score).
2. Open `outputs/x/daily-card.html` in a text editor, update the 5 fields
   marked `EDIT:` (date, 3 stat numbers, riskiest-token line), save.
3. Ask me (or any agent session) "render today's rug report card" — or open
   the HTML in a browser and screenshot the card.
4. Post with this caption:

```
🚨 Rug Report — [date]

[N] tokens scanned on RugRadar in the last 24h. [M] honeypots caught.

Riskiest: $[SYMBOL] — [one-line reason].

Scan before you ape: rugradar.trademetricspro.com
```

5. Through the day: reply to 5-10 fresh CA posts with a scan verdict +
   report link (the link unfurls the branded score card automatically).

## Launch day sequence (once)

1. Pin the pinned tweet (pack file POST 1) with `screenshot-home.png`.
2. Post the 6-post launch thread; attach `screenshot-home.png` to 1/,
   `screenshot-report.png` to 3/, `screenshot-feed.png` to 5/.
3. First Rug Report goes out the next morning.
